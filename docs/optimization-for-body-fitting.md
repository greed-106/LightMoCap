## 1. 整体概览

当将三维人体模型（如 SMPL-X）拟合到观测数据时——例如通过三角化得到的三维关键点，或来自多个摄像机的二维投影——实际上是在求解一个**反问题**：我们拥有不完美的测量值，希望恢复最能解释这些观测值的底层参数。

整个过程如下：

```
观测：
  "我在摄像机1中看到手部关键点位于像素 (320, 215)"
  "我在摄像机2中看到手部关键点位于像素 (480, 198)"
  "三角化后的三维位置在 (0.4, -0.2, 2.1)"

提问：
  "哪组 SMPL-X 参数（关节角度、全局旋转、平移、形状、表情）
   能够投影出与这些观测匹配的结果？"

回答：
  → 运行数值优化，找到最优参数
```

人体模型是一个**非线性函数** `M(θ)`，它将参数 `θ` 映射为三维网格和关键点。观测模型是一个**投影函数** `π(·)`，它将三维点映射到二维像素。优化过程不断调整 `θ`，直到预测的观测值与真实观测值尽可能接近。

---

## 2. 什么是优化问题？

从本质上讲，一个优化问题包含三个要素：

### 2.1 参数（我们能控制的变量）

在 SMPL-X 拟合中，我们优化的参数 `θ` 包括：

| 参数 | 含义 | 维度 |
|------|------|------|
| `Rh` | 全局旋转（罗德里格斯向量，Rodrigues vector） | 3 |
| `Th` | 全局平移 | 3 |
| `poses` | 身体、手部和头部的关节角度（轴角形式，axis-angle） | 165（55×3） |
| `shapes` | 身体形状系数（beta） | 10 |
| `expression` | 面部表情系数 | 10 |

总计，单帧约有 **191 个标量参数**。多帧拟合将这些堆叠成更长的向量。每个参数都是我们可以调整的实数。

### 2.2 目标函数（我们最小化的对象）

**目标函数**（也称为**损失函数**或**代价函数**）是一个标量函数，用于衡量给定参数组的"糟糕程度"。我们希望找到使这个数值尽可能小的参数。

形式化地表示为：

```
θ* = argmin_θ  f(θ)
```

其中 `θ*` 是最优参数向量，`f : ℝⁿ → ℝ` 是目标函数。

在 LightMocap 中，目标函数是**多个项的加权和**：

```python
loss = (
    weight_k3d     * loss_k3d        # 三维关键点损失
  + weight_k2d     * loss_k2d        # 二维关键点损失
  + weight_reg_poses * loss_reg_poses  # 姿态正则化损失
  + weight_smooth   * loss_smooth     # 平滑损失
  + ...more terms                       # 更多损失项
)
```

### 2.3 解空间

**解空间**是所有合法参数向量的集合。在**无约束**优化中，任何实值向量都是允许的。在**有约束**优化中，我们限制搜索范围——例如，旋转必须是合法的三维旋转，关节角度必须保持在解剖学限制范围内。

## 3. 最小二乘法：姿态拟合的主力方法

### 3.1 基本思想

最小二乘法是拟合问题最常见的表述方式。其思想很简单：我们有一组**残差**——即观测值与模型预测值之间的差异——我们希望最小化它们平方幅值的和。

如果有 `m` 个残差 `r₁, r₂, ..., r_m`，最小二乘目标函数为：

```
f(θ) = Σᵢ rᵢ(θ)² = ‖r(θ)‖²
```

其中 `r(θ) = [r₁(θ), r₂(θ), ..., rₘ(θ)]ᵀ` 是**残差向量**。

### 3.2 为什么要对残差平方？

有几个很好的理由：

1. **解析可处理性**：平方 `L2` 范数具有方便的导数形式。
2. **高斯噪声假设**：如果观测噪声服从高斯分布，最小化平方残差给出**最大似然估计**。
3. **可解释性**：每个残差的贡献与其偏离零的程度成正比。
4. **鲁棒化**：通过对平方项使用**鲁棒核函数**（如 Geman-McClure），可以在不放弃最小二乘框架的情况下减少异常值的影响。

### 3.3 身体拟合中的残差

在 LightMocap 中，三维关键点拟合的残差为：

```
r_k3d = (keypoints_3d_observed - keypoints_3d_predicted) * confidence
```

其中 `confidence` 加权意味着不可靠的关键点（例如检测器置信度低的关键点）对目标的贡献较小。

对于二维多视角重投影，残差为：

```python
# 将三维关键点投影到每个摄像机视角
img_points = projection(θ)               # 形状：(n_views, n_frames, n_joints, 2)
r_k2d = (img_points - keypoints_2d_observed) * confidence  # 逐像素误差
```

这是一个**非线性**最小二乘问题，因为 `keypoints_3d_predicted` 和 `img_points` 都是 `θ` 的非线性函数（它们来自 SMPL-X 正向传递，涉及旋转、蒙皮和透视投影）。

## 4. 无约束求解器：从梯度下降到牛顿法

### 4.1 梯度下降：沿着最陡峭的斜坡下行

目标函数的**梯度** `∇f(θ)` 指示了最大增大的方向。为了最小化，我们沿相反方向移动：**负梯度方向**。

**更新公式：**
```
θ_{k+1} = θ_k - α_k · ∇f(θ_k)
```

其中 `α_k` 是**步长**（也称为学习率，learning rate）。

**直观理解：** 想象你站在雾中山坡上。梯度告诉你哪个方向的下坡最陡。梯度下降法说：朝那个方向迈出一步。重复直到到达底部。

**优点：** 简单，对非凸问题有效，每步计算成本低。
**缺点：** 可能非常慢（在狭长山谷中走之字形路线），对步长敏感，需要很多次迭代。

对于约 191 个参数的大规模身体拟合，纯梯度下降法太慢了。

### 4.2 牛顿法：利用曲率信息

牛顿法更进一步：不仅应该下山，还应该考虑表面的**曲率**——斜率变化的快慢。

它用二阶泰勒展开将目标函数近似为**二次模型**（抛物线）：

```
f(θ + p) ≈ f(θ) + ∇f(θ)ᵀ p + ½ pᵀ H(θ) p
```

其中 `H(θ)` 是**海森矩阵**——二阶导数的矩阵，编码了完整的曲率信息。

令这个二次函数的导数为零，得到牛顿步：

```
H(θ) p = -∇f(θ)    ⟹    p = -H(θ)⁻¹ ∇f(θ)
```

**更新公式：**
```
θ_{k+1} = θ_k + p_k
```

**直观理解：** 二次近似精确告诉你局部抛物线的最小值在哪里。如果目标函数在最优解附近确实是抛物线形状，你可以一步到达最小值。

**优点：** 在最优解附近收敛快（二次收敛——误差每步平方减半）。
**缺点：** 计算和求逆海森矩阵开销大（对于 `n` 个参数的问题为 `O(n³)`）。对于 191 个参数，虽然可以接受但仍然代价不菲。更关键的是，海森矩阵可能不是正定的，因此牛顿步可能实际上并不下山。

### 4.3 拟牛顿法：高效近似海森矩阵

**拟牛顿**方法通过仅使用一阶梯度信息在迭代过程中逐步构建海森矩阵的近似 `B_k ≈ H(θ_k)`，从而避免昂贵的海森矩阵计算。

最著名的拟牛顿方法是 **BFGS**（Broyden-Fletcher-Goldfarb-Shanno）。它维护一个正定近似 `B_k`，并使用**割线方程**更新：

```
B_{k+1} s_k = y_k
```

其中 `s_k = θ_{k+1} - θ_k`（已执行的步长），`y_k = ∇f(θ_{k+1}) - ∇f(θ_k)`（梯度的变化量）。

完整的 BFGS 更新公式为：

```
B_{k+1} = B_k - (B_k s_k s_kᵀ B_k) / (s_kᵀ B_k s_k) + (y_k y_kᵀ) / (y_kᵀ s_k)
```

**LBFGS**（有限内存 BFGS）是实用的变体：它不存储完整的 `n × n` 矩阵，而是只存储最近 `m` 对 `{s_k, y_k}`，通常 `m = 5 到 20`。这将存储从 `O(n²)` 减少到 `O(mn)`。

**为什么 LBFGS 非常适合身体拟合：**

```python
# LightMocap 使用 LBFGS 和强 Wolfe 线搜索
optimizer = LBFGS(opt_params, line_search_fn="strong_wolfe", max_iter=20)
```

- 它利用曲率信息而不存储完整的海森矩阵。
- 对于非凸问题，它比纯牛顿法稳健得多。
- **强 Wolfe 线搜索**确保目标函数有足够的下降，防止步长过大。
- 对于约 191 个参数，`O(mn)` 的存储量可以忽略不计，但曲率信息显著加速了收敛，相比梯度下降效果明显。

## 5. 非线性最小二乘：高斯-牛顿与狗腿法

当目标函数具有特殊的最小二乘形式 `f(θ) = Σᵢ rᵢ(θ)² = ‖r(θ)‖²` 时，我们可以进一步利用这个结构。

### 5.1 雅可比矩阵

**雅可比矩阵** `J(θ)` 是残差向量的一阶导数矩阵：

```
J(θ) = ∂r/∂θ   — 形状：(m × n)
       m = 残差数量
       n = 参数数量
```

`J` 的每一行 `i` 是残差 `rᵢ` 相对于所有参数的梯度。

最小二乘目标函数的梯度和海森矩阵具有特殊形式：

```
∇f(θ)  = J(θ)ᵀ r(θ)                          [动量：n 维向量]
H(θ)   = J(θ)ᵀ J(θ)  +  Σᵢ rᵢ(θ) · Hᵢ(θ)    [n × n 矩阵]
```

### 5.2 高斯-牛顿法

**高斯-牛顿**法从海森矩阵中丢弃二阶项 `Σᵢ rᵢ · Hᵢ`，得到：

```
H_GN(θ) ≈ J(θ)ᵀ J(θ)
```

高斯-牛顿步求解：

```
Jᵀ J p_GN = -Jᵀ r
```

这是一个**线性最小二乘问题**（正则方程），可以用 Cholesky 分解或 QR 分解在 `O(n²)` 时间内求解——比求逆完整海森矩阵便宜得多。

**优点：** 比梯度下降快，不需要二阶导数，保证下降方向（因为 `JᵀJ` 总是半正定的）。
**缺点：** 仍然是近似——忽略了残差本身的曲率。在离最优解较远时可能停滞不前。

### 5.3 狗腿法

狗腿法是一种专门针对非线性最小二乘的**信赖域**方法（将在第 11 节讨论）。它比较两个候选步：

1. **柯西点**：限制在信赖域内的最速下降步。
2. **高斯-牛顿点**：完整的高斯-牛顿无约束步。

狗腿路径是从原点 → 柯西点 → 高斯-牛顿点的分段线性路径。该方法在当前信赖半径内沿这条路径选择最佳点。

这使得狗腿法比纯高斯-牛顿法更加稳健，尤其是当高斯-牛顿步可能超调时。

## 6. 列文伯格-马夸尔特：兼两家之长

**列文伯格-马夸尔特法（LM）** 是非线性最小二乘的主流算法。它通过一个**阻尼参数** `λ` 将高斯-牛顿法与梯度下降法融合：

```
(Jᵀ J + λ · diag(Jᵀ J)) p_LM = -Jᵀ r
```

当 `λ = 0` 时，这正是高斯-牛顿法。
当 `λ → ∞` 时，步长接近 `-(1/λ) · Jᵀ r`——一个极小的梯度下降步。

**自适应阻尼：** LM 自适应地调整 `λ`：
- 如果一步**降低**了目标函数值 → 接受该步，减小 `λ`（更信任高斯-牛顿近似）。
- 如果一步**增加**了目标函数值 → 拒绝该步，增大 `λ`（回落到梯度下降方向）。

**为什么 LM 对身体拟合如此有效：**
- 它自动在快速的高斯-牛顿模式（接近最优解时）和安全的梯度下降模式（远离最优解时）之间导航。
- 它对身体拟合中出现的病态条件（参数处于非常不同的尺度：旋转角度 vs. 平移 vs. 形状系数）具有稳健性。
- 它是许多先进拟合库（SMPLify、Vposer 等）的核心。

LightMocap 使用的是 **LBFGS** 而非直接使用 LM，但带强 Wolfe 线搜索的 LBFGS 提供类似的稳健性：它根据局部曲率自适应调整有效步长，并确保目标函数的单调下降。

## 7. 约束与无约束

### 7.1 硬约束与软约束

**硬约束**绝对禁止某些参数值：
- 关节角度 `θᵢ ∈ [-π, π]`
- 旋转矩阵必须正交（行列式 = +1）
- 形状系数有界：`|bᵢ| ≤ 3`（对于合理的人体形状）

**软约束**通过惩罚项将偏好编码到目标函数中（这就是 LightMocap 所做的）：

```python
# LightMocap：对大关节角度进行惩罚
loss_reg_poses = Σ(poses_i²)           # L2 正则化将姿态拉向零点
loss_reg_poses_zero = Σ|poses_i|       # L1 鼓励不相关关节恰好为零
```

`LossRegPosesZero` 类（第 8.2 节）就是一个很好的例子：它识别出不太可能可见的身体关节（如缺少地面接触时的脚、未检测到面部时的头部），并使用 `L1` 惩罚鼓励它们的姿态角度恰好为零——这是一种软约束，说的是"优先为零，但不严格执行"。

### 7.2 实际中如何处理约束

身体拟合通常使用软约束，原因有二：

1. **可微**：所有软约束项都是可微的，因此可以直接插入基于梯度的优化中。
2. **可调**：每个约束项的权重可以在每个阶段调整。

然而，一些约束是通过表示形式隐式处理的：

- 全局旋转 `Rh` 以**罗德里格斯向量**（按角度缩放的轴角）存储。LBS（线性混合蒙皮）正向传递通过指数映射将其转换为旋转矩阵，自动确保它是一个合法的旋转。
- 平移 `Th` 是无约束的——这没问题，因为目标函数自然将其拉向正确的位置。

## 8. 正则化：引导解的方向

### 8.1 为什么正则化至关重要

身体拟合是一个**病态反问题**：许多不同的参数向量可以产生相似的关键点。如果没有引导，优化器可能会找到一个物理上不合理但仍能匹配观测值的姿态。

**正则化**注入先验知识，引导解朝着物理上合理、平滑和稳定的结果发展。

### 8.2 LightMocap 中的正则化类型

**形状正则化**——偏好平均身体比例：
```python
loss_reg_shapes = Σ(b_i²)  / n_frames
```
这惩罚了与平均人体形状（`b = 0` 是平均 SMPL-X 身体）的大的偏离。权重 `5e-3` 很小——形状应该只缓慢变化，并且在有强证据支持时才变化。

**姿态正则化**——偏好自然姿态：
```python
loss_reg_poses  = Σ(poses_body²) / n_frames   # 权重：1e-3
loss_reg_hand   = Σ(poses_hands²) / n_frames   # 权重：1e-4
loss_reg_head   = Σ(poses_head²)  / n_frames   # 权重：1e-2
loss_reg_expr   = Σ(expr²)        / n_frames   # 权重：1e-2
```
这些将姿态参数拉向零点（T 姿态/中性配置）。权重经过调优，使姿态正则化是活跃的但不占主导地位——当证据充分时，数据项应该胜出。

**零角度先验**——`LossRegPosesZero` 使用 L1 正则化，在某些关节在图像中不可见时鼓励它们恰好为零：

```python
# 对于不可见的关节，惩罚：Σ|pose_i|
# 这是"那些关节没有移动"的软版本
loss_reg_poses_zero = Σ|poses[:, joint_indices]|   # 权重：1e-2
```

**初始化正则化**——防止从初始估计大幅跳跃：
```python
loss_init_poses  = Σ(poses - poses_init)²   # 权重：1e-2
loss_init_shapes = Σ(shapes - shapes_init)² # 权重：1e-2
```
这对于稳定性至关重要。如果优化器在前几次迭代中跳跃太远，SMPL-X 模型可能会产生退化的几何形状。这些项类似于**拉格朗日乘子**，限制每次迭代可以从起点走多远。

### 8.3 时间平滑正则化

对于多帧拟合，相邻帧应该有相似的姿态。`LossSmoothBodyMean` 惩罚快速变化：

```python
# 对于每个关节位置序列 P[0], P[1], ..., P[n]：
# 创建一个平滑版本 Q：
#   Q[0] = P[0]
#   Q[i] = (P[i-1] + P[i+1]) / 2   for 1 ≤ i ≤ n-1
#   Q[n] = P[n]
# 惩罚：Σ ||P[i] - Q[i]||²
loss_smooth_body = Σ(keypoints[i] - interp[i])²
```

`LossSmoothPoses` 和 `LossSmoothRh` 对姿态角度和全局旋转做同样的处理（先将罗德里格斯向量转换为旋转矩阵，因为直接在旋转向量空间插值在几何上是没有意义的）。

```python
loss_smooth_poses = Σ(poses[i] - interp_poses[i])²   # 权重：1e-1
loss_smooth_Rh   = Σ(Rot[i] - interp_Rot[i])²       # 权重：1e-1
```

这些平滑项使输出在时间上无抖动，这对下游动画使用至关重要。

## 9. 身体拟合的优化格局

### 9.1 非凸性

身体拟合的目标函数是**深度非凸**的。不存在保证的全局最小值——只有局部最小值。

**非凸性的来源：**

1. **模糊的观测**：二维图像提供模糊的深度信息。同一个二维关键点可能来自许多不同的三维位置。
2. **对称性**：身体的正面和背面在二维投影中看起来相似。优化器可能混淆左右肢体。
3. **退化构型**：许多不同的姿态向量产生相同的关键点布局（特别是对于被遮挡的关节）。
4. **模型非线性**：SMPL-X 涉及线性混合权重的蒙皮，在关节限制处可能产生不平滑行为。
5. **遮挡**：不可见的关键点不提供梯度信号，使它们的参数自由漂移。

### 9.2 许多局部最小值

可以把目标函数格局想象成夜间山脉——有许多山谷。梯度下降和局部优化器会停留在它们起始的山谷中。不同的起始点导致不同的局部最小值（不同的拟合姿态）。

**身体拟合中常见的局部最小值：**
- **肢体翻转**：由于正面/背面模糊导致左右臂/腿交换。
- **人体翻转**：身体在深度方向朝向错误。
- **肢体塌陷**：手臂扎入躯干。
- **漂浮者**：身体定位在错误的深度。
- **关节扭曲**：单个关节过度旋转，而不是自然的多关节姿态。

### 9.3 为什么局部最小值是可以管理的

尽管非凸格局，身体拟合通常效果良好，因为：

1. **良好的初始化**：三角化的三维关键点提供了强初始估计。优化器已经从一个接近正确解的地方开始。
2. **多阶段拟合**：每个阶段（形状、三维姿态、二维姿态）从相对良好的起点逐步细化。
3. **正则化**：先验项约束了搜索空间，有效地"填充"了浅的局部最小值。
4. **鲁棒损失函数**：GMOF 减少了可能将解拉向不良最小值的异常关键点的影响。

## 10. 关键数学对象

### 10.1 残差 `r(θ)`

**残差**是观测值与预测值之间的有符号误差：

```
r_i(θ) = y_i_observed - y_i_predicted(θ)
```

对于 `m` 个关键点和每个关键点 3 个坐标的三维关键点拟合：
```
r_k3d(θ) ∈ ℝ^(3m)     （每个 x、y、z 坐标对应一个标量）
```

对于 `V` 个视角、`F` 帧、`J` 个关节的二维多视角拟合：
```
r_k2d(θ) ∈ ℝ^(2 × V × F × J)   （每个关节在每个视角两个坐标）
```

残差是最小二乘优化的基本信息来源。所有求解器都通过最小化 `‖r(θ)‖²` 来工作。

### 10.2 雅可比矩阵 `J(θ)`

**雅可比矩阵** `J = ∂r/∂θ ∈ ℝ^(m × n)` 是一阶灵敏度的矩阵。元素 `(i, j)` 告诉你当参数 `j` 变化时残差 `i` 如何变化：

```
J_ij = ∂r_i / ∂θ_j
```

**为什么它很重要：**
- **高斯-牛顿**：用 `JᵀJ` 作为海森矩阵近似。
- **列文伯格-马夸尔特**：用 `(JᵀJ + λ·diag(JᵀJ))` 作为修正曲率。
- **梯度检验**：将数值 `∂r/∂θ` 与解析 `J` 进行比较，是调试实现的常用方法。

在 PyTorch/TensorFlow 中，雅可比矩阵通过**自动微分**（autograd）自动计算。当你调用 `loss.backward()` 时，autograd 计算每个参数的 `∂loss/∂θ`——这是链式法则在计算图上的高效应用。

### 10.3 海森矩阵 `H(θ)`

**海森矩阵** `H = ∂²f/∂θ² ∈ ℝ^(n × n)` 是目标函数的二阶导数矩阵。元素 `(i, j)` 告诉你当沿方向 `j` 移动时，沿方向 `i` 的梯度如何变化：

```
H_ij = ∂²f / (∂θ_i ∂θ_j)
```

**对于最小二乘目标函数 `f = rᵀr`：**

```
H = Jᵀ J  +  Σᵢ r_i · H_i(r)
```

第二项（涉及残差的二阶导数）计算代价高昂。**高斯-牛顿法丢弃它**，将 `JᵀJ` 视为足够的近似。**牛顿法保留它**以在最优解附近获得二次收敛。

**海森矩阵编码的信息：**
- **曲率**：目标函数沿不同方向弯曲的剧烈程度。
- **参数耦合**：非对角元素 `H_ij` 显示调整参数 `i` 如何与参数 `j` 相互作用。
- **条件数**：海森矩阵最大与最小特征值的比率决定了问题的难度。条件数大的病态问题会导致梯度下降走之字形路线。

对于身体拟合，海森矩阵通常是病态的，因为不同参数的尺度差异很大：旋转角度改变 1 弧度对目标函数的影响与平移改变 1 米的影响截然不同。

## 11. 信赖域方法

### 11.1 基本思想

**信赖域**方法不是先选方向再决定走多远（线搜索），而是先选择一个最大步长（"信赖半径" `Δ`），然后在该半径内找到最优步长。

**信赖域内的二次模型：**
```
minimize  m_k(p) = f(θ_k) + g_kᵀ p + ½ pᵀ B_k p
subject to  ‖p‖ ≤ Δ_k
```

其中 `g_k = ∇f(θ_k)` 是梯度，`B_k` 是海森矩阵的近似。

### 11.2 信赖域如何自适应

执行步 `p_k` 后，我们比较实际下降量与预测下降量：

```
ρ_k = (f(θ_k) - f(θ_k + p_k)) / (m_k(0) - m_k(p_k))
```

- **`ρ_k ≈ 1`**：模型很好地预测了现实 → **扩大**信赖半径（`Δ_{k+1} > Δ_k`）。
- **`ρ_k ≈ 0`**：模型不准确 → **缩小**信赖半径（`Δ_{k+1} < Δ_k`）。
- **`ρ_k < 0`**：目标函数增加了 → **拒绝**该步，缩小半径。

### 11.3 信赖域框架中的狗腿法

在信赖域内，**狗腿法**沿着分段线性路径找到最优解：
1. 从 `θ` 到柯西点（限制在信赖半径内的最速下降）。
2. 从柯西点到高斯-牛顿点。

在该路径上、在半径为 `Δ` 的圆内的最优解就是狗腿步。

这给出了一种方法：
- 远离最优解时表现得像梯度下降（小的 `ρ_k`，缩小的 `Δ`）。
- 接近最优解时表现得像高斯-牛顿（大的 `ρ_k`，扩大的 `Δ`）。

### 11.4 为什么信赖域比线搜索更适合困难问题

线搜索假设如果你沿一个好的方向移动一小步，目标函数就会下降。但对于像身体拟合这样的高度非凸问题，这个假设会失效：即使对于小的 `α`，模型 `f(θ_k + αp_k)` 可能仍然是对现实的很差近似。

信赖域通过只在小的半径内信任局部二次模型来避免这个问题。如果模型很差，信赖半径会缩小，直到模型变得可靠。

**带强 Wolfe 线搜索的 LBFGS**（LightMocap 使用）提供类似的稳健性：线搜索检查目标函数确实下降后才接受一步。但信赖域方法提供了更有原则的自适应步长调整。

## 12. 多分辨率与由粗到精拟合

### 12.1 为什么由粗到精有效

身体拟合从**由粗到精**（也称为多分辨率或渐进式）优化中获益巨大：

1. **先抓大局**：从粗略的初始猜测开始时，优化器应该先关注重大决策（人在哪里？全局方向是什么？），然后再微调关节角度。
2. **避免局部最小值**：粗粒度模型的格局更平滑，局部最小值更少。求解粗粒度问题为细粒度问题提供了良好的起点。
3. **计算效率**：求解许多简单问题（粗阶段）比从头求解一个困难问题（完整细节）更快。
4. **数值稳定性**：早期阶段的大参数变化可能使 SMPL-X 正向传递在数值上不稳定。由粗到精使优化器保持在稳定区域。

### 12.2 LightMocap 如何实现由粗到精

LightMocap 的 `SMPLXFittingPipeline.fit()` 实现了三阶段流程——一种由粗到精的形式，每个阶段添加更多参数和更多复杂性：

```
阶段 1：fit_shape()（拟合形状）
  ├─ 优化：形状参数（10 个参数）
  ├─ 损失：肢体长度一致性（s3d）+ 形状正则化 + 初始化正则化
  ├─ 阶段目标：使人物的身体比例正确
  └─ 最大迭代次数：10

阶段 2：fit_pose3d()（拟合三维姿态）
  ├─ 优化：Rh、Th、姿态（≈171 个参数）+ 表情
  ├─ 损失：三维关键点对齐（k3d、k3d_hand、k3d_face）
  │         + 姿态/头部/手部正则化
  │         + 平滑项 + 初始化正则化
  ├─ 阶段目标：匹配三角化的三维关键点
  └─ 最大迭代次数：20

阶段 3：fit_pose2d()（拟合二维姿态）[可选，当有二维数据时启用]
  ├─ 优化：Rh、Th、姿态 + 表情
  ├─ 损失：多视角二维重投影（k2d）
  │         + 姿态/头部/手部正则化
  │         + 平滑项 + 初始化正则化 + 零角度先验
  ├─ 阶段目标：利用完整的多视角二维证据进行细化
  └─ 最大迭代次数：20
```

**阶段 1 → 阶段 2** 是经典的由粗到精过渡：形状固定后，阶段 2 冻结它们并优化姿态。阶段 1 的形状估计永远不会再被修改。

**阶段 2 → 阶段 3** 是细化：阶段 3 以阶段 2 的结果为起点，有效地在更好的局部最小值上"放大"。二维重投影项的残差比三维项多得多（每个摄像机视角一个，而不只是每个三角化点一个），为精细调整提供了更密集的梯度信息。

### 12.3 损失函数中的渐进复杂性

损失组成也反映了由粗到精的策略：

```
阶段 1：简单形状 + 先验
阶段 2：数据项（三维）+ 先验 + 平滑性
阶段 3：数据项（二维、多视角）+ 更强先验 + 平滑性
```

早期阶段强调正则化（塑造格局），而后期阶段强调数据项（利用格局来细化细节）。

## 13. 融会贯通：LightMocap 的拟合流程

以下是将本指南中的概念映射到实际 LightMocap 实现的方式：

### 优化器：LBFGS

```python
optimizer = LBFGS(opt_params, line_search_fn="strong_wolfe", max_iter=20)
```

**LBFGS** 是一种拟牛顿方法：它利用梯度历史（最近约 100 步）近似海森矩阵，避免了完整海森矩阵计算的 `O(n³)` 代价，同时仍然利用了曲率信息。`strong_wolfe` 线搜索保证目标函数有足够的下降。

拟合循环（在 `FittingMonitor.run_fitting` 中）：

```python
for iteration in range(maxiters):
    loss = optimizer.step(closure)       # 执行一步 LBFGS
    if rel_change(prev_loss, loss) <= ftol:  # 收敛了吗？
        break
```

### 目标函数：加权和损失

每个拟合阶段构建一个损失项字典：

```python
loss_dict = {
    "k3d":         loss_k3d.body(kpts_est),       # 三维关键点损失
    "smooth_body": loss_smooth_body.body(kpts_est),  # 身体平滑损失
    "smooth_poses":loss_smooth_pose.poses(poses),    # 姿态平滑损失
    "smooth_Rh":  loss_smooth_rh(Rh),             # 全局旋转平滑损失
    "reg_poses":  loss_reg_pose.reg_body(poses),  # 姿态正则化损失
    "reg_shapes": loss_reg_shapes(shapes),        # 形状正则化损失
    "init_poses": loss_init.init_poses(poses),    # 姿态初始化正则化
    "init_shapes":loss_init.init_shapes(shapes),  # 形状初始化正则化
}
loss = sum(loss_dict[name] * weight_loss[name] for name in loss_dict)
```

权重字典编码了先验知识：

| 权重 | 值 | 作用 |
|------|-----|------|
| `k3d` | 1.0 | **数据项**：姿态的主要证据 |
| `k3d_hand` | 5.0 | 手部更强的证据（更难三角化） |
| `k3d_face` | 2.0 | 面部适中的证据 |
| `k2d` | 1e-4 | 轻微的二维重投影细化 |
| `reg_poses` | 1e-3 | 先验：偏好中性姿态 |
| `reg_shapes` | 5e-3 | 先验：偏好平均身体形状 |
| `smooth_*` | 0.1–0.5 | 先验：偏好时间平滑性 |
| `init_*` | 1e-2 | 先验：不要偏离初始估计太远 |

`k3d_hand`（5.0）的大权重补偿了手部关键点比身体关键点更嘈杂、更难三角化的事实。

### 鲁棒损失：GMOF

二维重投影损失使用 **Geman-McClure** 鲁棒函数：

```python
def gmof(squared_residual, sigma_squared=200.0):
    # Geman-McClure 鲁棒核函数：抑制大的残差
    return (sigma_squared * squared_residual) / (sigma_squared + squared_residual)

squared = gmof(residual**2, sigma_squared=200.0)
```

这变换了平方残差，使得远大于 `σ²` 的残差贡献一个常数（`σ²`）而不是无限增长。这使优化器对异常值（如在错误位置检测到的被遮挡手部关节）具有稳健性。

### 收敛监测

```python
def rel_change(prev_val, curr_val):
    # 计算相对变化量
    return abs(prev_val - curr_val) / max(abs(prev_val), abs(curr_val), 1.0)

if rel_change(prev_loss, loss.item()) <= ftol:  # ftol = 1e-4
    break  # 收敛：相对变化小于 0.01%
```

## 总结：完整流程

```
输入：
  - 多视角图像
  - 二维关键点检测（来自 rtmlib）
  - 相机参数（K、R、T）
  - 可选：三维关键点（来自三角化）

步骤 1：形状估计  （LBFGS，10 次迭代，≈10 个参数）
  → 肢体长度一致性损失 + 形状先验
  → 输出：betas（身体比例）

步骤 2：三维姿态估计  （LBFGS，20 次迭代，≈170 个参数）
  → 三维关键点对齐损失（鲁棒的 GMOF）
  → 姿态/手部/面部正则化
  → 时间平滑性（多帧）
  → 输出：Rh、Th、poses、expression

步骤 3：二维姿态细化  （LBFGS，20 次迭代，≈170 个参数）
  → 多视角二维重投影损失（鲁棒的 GMOF）
  → 更强的正则化（更小的初始化权重）
  → 不可见关节的零角度先验
  → 输出：细化的 Rh、Th、poses、expression

输出：
  - SMPL-X 参数（可导出网格/顶点）
```

每一步都是**无约束非线性最小二乘优化**，使用带**强 Wolfe 线搜索**的 **LBFGS**，通过基于梯度的曲率近似来利用问题结构。每个阶段的**正则化**编码了物理先验，而**由粗到精的流程**防止优化器陷入不良的局部最小值。
